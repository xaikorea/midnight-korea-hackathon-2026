# 신규 사례의 공식 접수 경로와 Midnight 실행

공개 안내를 참고한 6개 사례의 준비 기록에서 공식 사이트를 열고, 별도 동의로 신규 Local Devnet 거래를 요청할 수 있다. 공식 접수 API·협약 계정은 연결되지 않았다. **공식 사이트 이동, 내부 준비 기록, 체인 조건 검증, 기관 접수·선정은 각각 다른 상태**다. 합성 자료를 실제 기관에 제출하지 않는다.

| 사례 | 체인에서 확인하는 범위 | 체인 결과에 포함하지 않는 사항 |
|---|---|---|
| 서울창업허브 성수 | 기준일의 일반 업력 또는 서명 근거가 있는 신산업 업력 경로 | 신산업의 실기관 인정, 수혜 이력, IR 내용, 최종 선정 |
| 서울 AI 허브 선도기업 | 해당 연도 매출 또는 누적 투자 조건, 최소 상주 인원 | 실제 투자 인정·근무 여부, AI 적합성, 선정; 종료된 회차 |
| 서울창업허브 공덕 | 입주 예정일 기준 업력 경로 | 납세·서류 내용·이전 약정·선정; 종료된 회차 |
| 현대제철 / POSCO / SK하이닉스 | 서명된 기업 자격 묶음과 보유자·수신 대상·제출 요청의 연결 | 기술 시험, 품목별 신용·ESG·구매 심사, 협력사 등록 |

## 실행 순서

1. 합성 기업 자료로 사전검사 후 준비 기록을 저장한다.
2. 준비 기록의 `이 신청의 새 체인 실행 요청`에서 원본 처리 및 체인 기록에 별도 동의한다. 실행 동의는 90분간 유효하며 기존 5분 준비 동의를 연장하거나 재사용하지 않는다.
공개 자동 모드에서는 대상·시연 사례를 선택하고 최초 동의 후 `동의한 자료로 자동 시연 시작`을 누르면 1~3을 서버에서 이어서 처리한다. 아래 3의 수동 승인은 자동 모드가 꺼진 경우에만 필요하다.

3. 별도 서비스 관리자가 `/admin/proof-jobs`에서 해당 신규 사례를 승인한다. 일반 체험 역할 전환으로 승인할 수 없다.
4. 기존 실행기가 한 번에 한 작업을 처리한다. 별도 `program-core.compact` 계약을 배포하고 원본 서명·기업·현재 유효성·서류 해시를 다시 검사한다.
5. 실행기가 검증한 합성 원본을 Schnorr 집계 자격에 연결한다. 발급자 등록, 기준 시간, 요청 등록, 조건 제출의 실제 거래를 생성한다.
6. 별도 검증기가 컴파일된 계약 키, 거래 ID·블록·실제 실행 함수, 요청의 보유자·수신자·nonce·회사·프로필·정책·동의 기한과 결과를 읽기 전용으로 대조한다. 서명된 검증 보고서를 수신해야 `새 거래 검증 완료`가 된다.

실행 중 원본이 변경되거나 취소·만료되면 새 제출을 차단한다. 통신이 중단된 거래는 개인 실행 기록과 인덱서에서 먼저 대조하며, 전송 여부를 알 수 없으면 자동 재전송하지 않는다. 동의가 지난 거래는 새 동의로 요청해야 한다. 신규 합성 자격에는 별도 실기관 취소 API가 연결되어 있지 않으므로 과거 성공 결과를 현재 유효성으로 재사용하지 않는다.

## 신뢰와 공개 범위

네트워크는 `undeployed` Local Devnet이며 퍼블릭 Preprod/Mainnet이 아니다. 합성 발급자의 원본 Ed25519 서명은 웹과 실행기가 검사한다. 실행기는 미리 고정한 플랫폼 공개키로 합성 발급자 키 배정을 확인한다. 이것은 실제 기관의 신뢰 루트나 공식 발급 자격을 의미하지 않는다. 회로는 Ed25519 원본을 직접 검증하지 않고 실행기의 Schnorr 집계 자격을 검증한다.

원본 속성과 PDF는 체인에 올리지 않지만 조건, 가명 식별자, 프로필·자격 묶음 commitment, 결과는 공개 상태다. 조건 결과로 값의 범위를 추론할 수 있다. 검사하지 않는 회로 필드의 0은 비활성 조건을 위한 자리값이며 미확인 검사값을 대신하지 않는다. 사용자 API는 원본 속성·개인키·실행 인증 비밀을 반환하지 않는다.

## 공식 접수 경로

- [성수 공고](https://www.startup-plus.kr/project/PRJ007420): 로그인 후 공식 신청 화면과 지정 서식을 사용한다.
- [AI 허브 종료 공고](https://www.startup-plus.kr/project/PRJ006524), [공덕 종료 공고](https://hubgongdeok.startup-plus.kr/project/PRJ006640): 현행 접수로 표시하지 않는다.
- [현대제철 기술제안](https://tech.hyundai-steel.com/ko), [POSCO 구매 포털](https://my.posco.com/), [SK하이닉스 GPIS](https://gpis.skhynix.com/): 해당 사이트의 계정·품목·심사 절차를 따른다.

자동 접수에는 기관별 공식 API/협약, 테스트 계정, 접수번호 조회와 중복 제출·취소·상태 회신 규격이 필요하다. 현재는 링크를 여는 것만으로 접수 기록을 만들지 않으며 `officialReceipt`는 `null`이다. 비공개 접수 API를 추측하거나 로그인 화면을 우회하지 않는다.

## 재현 검증

`npm run test:verification`에 신규 사례 원본 변조·타깃 변경·중복 작업·동의 만료·권한·독립 검증 서명·재전송 방지 검사가 포함된다. `tests/program-proof-jobs.cjs`는 격리된 합성 자료와 가상 영수증을 사용하며 실제 체인 실행 증거가 아니다. 실제 실행 증거는 승인한 작업의 확정 영수증과 별도 검증 보고서에서 확인한다.
