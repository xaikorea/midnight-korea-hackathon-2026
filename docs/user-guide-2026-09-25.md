# 이용자 가이드 — 2026-09-25 최신 흐름

공개 `/guide`와 업무 메뉴의 `/?view=guide`는 같은 컴포넌트와 안내 데이터를 사용한다. 이전의 기본 신청 안내에 별도 발급 서버와 신규 6개 사례의 실제 실행 절차를 추가했다.

## 처음 방문한 사용자

- 준비된 자격으로 빠르게 두 곳에 신청하기
- 별도 발급 서버의 신청 → 보완 → 검토·서명 → 지갑 수신 → 두 기관 재사용
- 실제 기관·구매사 사례의 합성 자료 불러오기 → 사전 확인 → 내부 준비 기록 → 선택적 Midnight 실행

세 경로를 모두 수행할 필요는 없다. 기본 신청의 대상 선택·공유 동의·제출은 그대로 세 단계로 안내한다.

## 최신 안내 범위

기능별 안내 28개와 FAQ 16개를 제공한다. 검색에는 비교표 내용도 포함되며, 바로가기를 누르면 검색을 해제하여 해당 안내가 숨겨지지 않도록 한다.

- 성수·AI 허브·공덕·현대제철·POSCO·SK하이닉스 각각의 체인 증명 범위와 남아 있는 실제 심사
- 정상 자료와 투자 대체·이력 미확인·연도 불일치·납세 만료·IR 분량 초과·수치 미충족 비교
- 준비 동의 5분, 실행 동의 90분, 체험 세션 2시간의 구분
- 신규 사례 요청 및 별도 서비스 관리자의 승인, 실행기 대기, 실제 증명·전송, 독립 검증
- 체인 상태 8종과 취소·차단·복구 시 조치, 작업당 정상 영수증 5건 확인
- 기존 두 기관 자격 재사용 작업과 신규 사례 작업의 차이
- 공식 접수 API 미연결, 종료 회차 표시, JSON 목록과 공식 신청서·접수증의 차이
- 기록 재생·영상의 이전 완료 결과와 현재 사용자 작업의 구분

## 설명의 경계

Local Devnet 거래를 퍼블릭 Preprod·메인넷 검증으로 설명하지 않는다. 원본 Ed25519 서명은 서버와 실행기가, 회로용 Schnorr 자격은 회로가 검증한다. 구매사 세 사례는 기업 자격과 요청 연결을 증명하며 기술·신용·ESG 심사를 대신하지 않는다. 합성 자료를 공식 기관에 제출하도록 안내하지 않는다.

현재 구현 기준은 `app/program-applications.tsx`, `app/program-proof-panel.tsx`, `lib/program-proof-jobs.ts`, [신규 사례 실행 설명](program-execution.md)이다. 관리자 비밀번호, 운영 서버 식별 정보, 개인 실행 기록, 방문자 정보는 가이드에 포함하지 않는다.

## 검증

`tests/user-guide-ui.cjs`는 3개 체험 경로, 6개 사례·8개 상태·7개 자료 비교표, 검색·앵커 이동, FAQ, 모바일 화면과 로그인한 업무 메뉴 연결을 확인한다. `GUIDE_PUBLIC_ONLY=1`은 새 체험 공간이나 신청을 생성하지 않고 공개 페이지를 검증한다. 코드 변경 시 타입 검사와 변경 파일 린트를 함께 수행한다.
