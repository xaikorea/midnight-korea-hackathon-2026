# 입구 페이지 모션 배경

2026-09-22. 공개 홈과 `/welcome`에 동일하게 적용한다.

- 브랜드의 파랑·청록색을 사용하는 12초 무음 배경 영상, 움직이는 빛과 네트워크 궤도.
- 로고를 담은 자격 카드의 부유·광택 효과, 주변 궤도의 회전, 구매사·지원기관으로 이어지는 빛의 연결선.
- 안내 문구와 시작 버튼 영역은 밝은 가림막을 적용해 배경 움직임과 관계없이 읽을 수 있도록 구성.
- 배경 움직임 정지/재생 버튼. 현재 탭에서 정지 선택을 기억하며, 화면 밖 또는 숨겨진 탭에서는 재생을 중지.
- `prefers-reduced-motion` 또는 `Save-Data`가 활성화되면 처음에는 영상 요청 없이 정지 이미지 표시. 사용자가 재생을 선택하면 동작.
- 모바일에서는 768px 영상 사용. 영상 오류·자동 재생 차단 시 이미지 또는 멈춘 프레임 유지. 체험 시작은 영상 준비와 무관하게 가능.
- 외부 영상 플랫폼·광고·음악 없이 프로젝트에서 직접 만든 그래픽 사용. 파일 출처와 재생성 방법은 `public/media/README.md` 참고.

구현: `app/welcome-motion.tsx`, `app/welcome-motion.css`, `app/welcome-screen.tsx`.

검증 항목: 실제 무음 재생, 정지/재개, 정지 선택 유지, 화면 밖 정지, 로딩·재시도 버튼, 모바일 재생·너비, 동작 줄이기·데이터 절약 시 영상 미요청, 영상 실패 시 기본 화면 유지.

배포 완료: 앱 코드 `ad22876`, 이미지 `bizproof:welcome-motion` (`518809777f10`). 운영과 분리된 컨테이너 및 공개 HTTPS 주소에서 위 브라우저 검증을 통과했다. 공개 MP4 2개·포스터의 SHA-256이 원본과 일치하며 영상 Range 요청이 206/1,024 bytes로 응답함을 확인했다. 타입·ESLint·전체 배포 단위 테스트·Node 런타임·Next 빌드 통과. 공개 화면 캡처는 `outputs/welcome-motion-desktop.png`, `outputs/welcome-motion-mobile.png`에 저장했다.
