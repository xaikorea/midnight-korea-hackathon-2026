# Professional light design

The platform uses a light enterprise workspace theme across public entry, applications,
organization and supplier profiles, verification, process monitoring, guides, and administration.

## Visual system

- Page: `#f5f8fb`; surfaces: white; primary text: `#20364b`.
- Primary actions: `#1d5caa`; secondary text: `#536b80`.
- Proof and completion: teal/green on a pale background. Blocked and unmet conditions:
  amber on a pale background. Labels and icons continue to convey these states.
- Pale blue/teal hero panels, thin borders, subtle shadows and a shared system font stack
  replace the large dark panels. Selected navigation retains an explicit indicator.
- Native inputs and application tokens explicitly use the light color scheme, including
  when the visitor's operating system prefers dark mode.
- The entry video remains available at reduced opacity behind a stronger light veil.
  Pause and reduced-motion controls are preserved.

The blockchain stage illustrations use coordinated light SVG fills, darker outlines and
readable labels. The CSS changes do not alter transaction state, receipt validation,
preview vs. recorded playback, or actual submission processing.

## Verification

Use the existing blockchain visualization, user guide and application process browser
checks. Inspect entry, application, organization, supplier, guide, process, verification
and administrator pages at desktop and 390px mobile widths, including an OS dark preference.
Authentication and data retention are unchanged. Screenshot artifacts belong in ignored
`outputs/`, not in the public source repository.
