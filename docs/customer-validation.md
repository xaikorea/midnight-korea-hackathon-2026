# 실제 업무 피드백 기록 양식

현재 상태: **실제 구매사·지원기관의 도입 수요를 확인한 자료는 아직 확보되지 않았다.** 기존 사용자 피드백은 절차를 줄이고 처리 과정을 설명해 달라는 내용이며, 이를 3단계 신청과 처리 기록 관제로 반영했다. 산업 수요 검증과 구분한다.

외부 담당자에게 자동으로 연락하거나 응답을 만들어 기록하지 않는다. 사용자가 제공하거나 직접 확보한 의견만 아래에 추가한다.

| 항목 | 기록 |
|---|---|
| 인터뷰 날짜·담당 업무 | 미확인 |
| 반복해서 제출/수집하는 기업 서류 | 미확인 |
| 실제 등록·지원사업 조건의 예 | 미확인 |
| 원본 수치가 필요한 항목 / 조건 충족만 필요한 항목 | 미확인 |
| 타 기관 발급 자격을 인정할 요건 | 미확인 |
| 만료·취소·정보 변경 확인 방법 | 미확인 |
| 현재 업무 시간·횟수와 측정 방법 | 미측정 |
| 시연 후 의견과 도입 의향 | 미확인 |
| 공개 인용 허용 범위 | 미확인 |

질문은 ‘우리 서비스가 좋은가’보다 현재 절차와 필요한 증거를 중심으로 한다. 예: “최근 공급사 한 곳을 등록할 때 받은 서류와 재확인 항목은 무엇이었나요?”, “매출 원문이 필요한가요, 특정 기준 이상이라는 결과로 충분한가요?”

신청서에는 확인한 사실, 담당자의 의견, 개발팀의 가설을 구분한다. 응답 수·시간 절감률·고객사 이름·도입 의향을 추정해 기재하지 않는다.
