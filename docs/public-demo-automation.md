# 공개 합성 데이터 자동 시연

2026-09-26. 서버에서 `BIZPROOF_PUBLIC_DEMO=true`와 `BIZPROOF_DEMO_AUTO_RUN=true`를 함께 설정하면 활성화된다. 기본 설정은 수동 모드다. 일반 사용자·Keycloak 실증·외부 기관 심사에는 적용하지 않는다.

- **실제 기관·구매사 준비:** 대상과 시연 사례 선택 → 원본 처리·기록·Local Devnet 범위에 한 번 동의 → 자동 시연 시작. 서버가 합성 PDF·서명 자격 준비, 사전검사, 준비 기록 저장, 실행 허용을 수행한다. 기존 실행기와 독립 검증기가 실제 거래를 처리한다.
- **별도 발급:** 동의하고 자동 발급·수신을 누르면 고정 합성 자료의 모의 검토, 기관 전용 키 서명, 지갑 원본 검증과 저장을 이어간다. 두 수신 대상에 제출할 때는 그 대상에 대한 공유 동의가 필요하다. 체인 실행 요청 뒤 관리자 승인은 자동 처리한다.
- **수동 체험:** 개별 자료 준비·검사·저장·체인 요청과 기관 검토 화면은 유지한다. 자동 모드가 꺼져 있으면 체인 요청은 종전처럼 관리자 승인 대기다.

자동 실행 기록에는 `approvalMode: automatic-synthetic`과 시스템 실행 주체를 저장한다. 원래 원본 서명·취소·만료·actor/owner·자격/요청 연결, 작업 한도, 원자적 실행기 임대와 독립 검증은 그대로 적용한다. 체인 요청 전에 원본을 다시 확인한다.

반복 클릭·응답 유실 후 같은 대상·기업·검사 fingerprint의 기록과 작업을 재사용한다. 준비 저장 후 실행 요청만 실패하면 준비 기록과 오류를 함께 반환한다. 수신 충돌은 현재 저장소를 다시 읽어 동일 기관 자격을 저장한다. 이전의 보완·반려·철회를 자동 승인하지 않는다. 전송 여부가 불확실한 `needs_attention` 작업은 관리자가 거래를 대조하기 전까지 멈춘다.

**자동 시연 완료는 공식 기관의 접수·선정·구매 승인이 아니다.** 미충족·자료 누락·담당자 확인은 그대로 남는다. 단순 대기열 등록으로 체인 성공을 표시하지 않으며, 실제 영수증과 별도 검증기 서명이 있어야 완료된다. 개발용 Local Devnet 전용이며 퍼블릭 Preprod/Mainnet 실행을 활성화하지 않는다.

검증: `tests/demo-automation.cjs`, `tests/demo-issuance-automation.cjs`, `tests/demo-automation-ui.cjs`, 기존 프로그램/발급/체인 회귀 검사. 단위·격리 브라우저 검사는 실제 체인 거래를 생성하지 않는다.
