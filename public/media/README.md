# BizProof 입구 페이지 배경 영상

2026-09-22 프로젝트를 위해 직접 제작한 절차적 모션 그래픽이다. 기업 자격 하나에서 여러 기관으로 이어지는 연결을 궤도·네트워크·빛의 흐름으로 표현한다. 외부 스톡 영상, 음악, 사진, 글꼴, 제삼자 로고를 사용하지 않는다.

| 파일 | 규격 | 용량 |
| --- | --- | --- |
| credential-network.mp4 | 1280×720, 24fps, 12초, H.264, 무음 | 889,933 bytes |
| credential-network-mobile.mp4 | 768×432, 24fps, 12초, H.264, 무음 | 291,760 bytes |
| credential-network-poster.webp | 1280×720 정지 프레임 | 35,022 bytes |

재생성: `python scripts/render-welcome-motion.py` (Pillow, NumPy, FFmpeg 필요). 앱 실행에는 이 제작 도구가 필요하지 않다. 영상에는 오디오 스트림이 없으며 끝과 시작이 이어지는 반복 재생을 전제로 제작했다.

영상은 장식용이다. 기업 자격·기관 이름·신청 안내는 영상에 합성하지 않고 접근 가능한 HTML로 별도 제공한다. 실제 거래나 검증 진행 상황을 표시하는 영상이 아니다.
